# Swipe Keyboard v0.5.1-1

[Downloads](https://github.com/itsdestin/swipe-keyboard/releases/tag/v0.5.1-1) · Install steps: [README](../../README.md#install). Full list of changes: [CHANGELOG](../../CHANGELOG.md).

A small update. Typing and word suggestions are the same as 0.5.0.

## What changed

- **Steam Deck: Gaming Mode is part of the one install.** The installer lists every change, then asks one question, **Also swipe in Gaming Mode? [Y/n]**. Enter means yes, with other devices on your network kept away from Steam's developer switch (it asks for the Deck's administrator password once). If you answered no before, a newer installer keeps no as its default.
- **Gaming Mode:** a Steam page reload during a check no longer counts against the keyboard layer.
- **Ready for the new name.** The project will be renamed OpenSwipe. Arch and Fedora installs now know the future update address as well as today's, so they keep updating through the rename. Nothing changes for you now.

## What to know before upgrading

- Already installed? Nothing to do: it updates itself.
- Steam Deck Gaming Mode is still new and tested only on a virtual Deck.
