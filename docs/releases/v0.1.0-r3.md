# Swipe Keyboard v0.1.0-r3 — safety and compatibility test release

**English swipe typing for KDE Plasma Keyboard, powered by FUTO Swipe.** No ASUS/Z13 hardware, tablet bundle, theme, agent or YouCoded account required.

Use the native **0.1.0-3** packages below. They supersede the older v0.1.0 downloads without replacing those historical files.

Requires **native Plasma Keyboard 6.7/6.8 in KDE Plasma Wayland**, a touchscreen, Qt **6.11 or newer within Qt 6**, and glibc **2.43 or newer**. Qt 6.11/6.12 are the verified minors. Not Maliit, GNOME, X11, ARM, Windows or a universal old-KDE compatibility claim.

**A full system update is not required merely to match the build machine's package revisions.** Real ABI requirements remain enforced; startup checks native-library loading before changing settings. Do not force dependencies or downgrade individual desktop libraries.

## Install

Download the package for your distro, then:

```sh
# Arch/CachyOS
sudo pacman -U ./swipe-keyboard-0.1.0-3-x86_64.pkg.tar.zst

# Fedora 44 KDE
sudo dnf install ./swipe-keyboard-0.1.0-3.fc44.x86_64.rpm
```

Inside your normal logged-in KDE desktop, **not sudo**:

```sh
swipe-keyboard check
swipe-keyboard enable
```

Touch a normal field; the spacebar should show **American English / English (US)**. Try two swiped words, a word alternative and the first on-screen Backspace. Before package removal, run `swipe-keyboard disable` as that same user. See the [setup/recovery guide](https://github.com/itsdestin/swipe-keyboard#install).

Existing custom layouts are preserved and refused, not overwritten: arrange an explicit migration first. The legacy developer `install.sh` is not the end-user installer.

## Changes

- Cancel stale gestures across focus/password, input-method and geometry changes; reject unsafe recognition/commits before insertion.
- Guard word-alternative replacement against selections and sensitive/uncertain context.
- Bound very long gestures and retain ordinary tapping/whole-word undo behavior when exact field context is available.
- Remove generated private Qt-minor ABI dependencies; build against an older baseline and check actual native loading on newer runtimes.
- Replace recursive build-machine version stamping with direct dependencies and real symbol-version floors; no fakeroot/transitive-version contamination.
- Add clearer diagnostics, recovery instructions and optional agent assistance. Informational logging no longer prints candidate words.

## Verified, with boundaries

- **Same Arch archive:** Qt 6.11.1 / Frameworks 6.27 / Keyboard 6.7.2 → Qt 6.12.0 / Frameworks 6.31 / Keyboard 6.8.0; extraction/loading and native install/check/removal pass, with identical before/after archive hashes.
- **CachyOS device:** the exact package's dependencies already satisfied; isolated swipe/safety tests passed; installed payload and active system-plugin loading verified without an OS update. Human touchscreen feedback is separate.
- **Exact Fedora RPM in a full KDE VM:** real touchscreen swipes, alternatives/undo, focus-to-password cancellation, interrupted/long-gesture recovery and typing/saving in ordinary KWrite. Prior safety-candidate acceptance also covered reboot, settings restoration and uninstall recovery.
- **Checks:** 18 native suites, 32 setup/overlay tests, 31 packaging tests and 6 guest-input safety tests. The packaging suite's Arch-only metadata check is skipped on Fedora where makepkg is absent.

See [full revision-3 verification](https://github.com/itsdestin/swipe-keyboard/blob/main/docs/revision3-verification.md). Container/offscreen checks are not full Arch compositor or physical-hardware acceptance.

**Known limits:** English swipe only; Firefox physical Ctrl+A/Delete may cause an extra leading space; missing/stale field information or initial focus synchronization may conservatively leave ordinary character deletion instead of whole-word undo. Keyboard appearance depends on application text-input support. Portrait/multi-touch/browser-specific acceptance was not separately rerun for this revision.

There is **no automatic update feed or AUR/COPR repository yet**. Signed update channels and ongoing maintenance automation are follow-up work, not part of this release. These local-download test packages are not presented as a signed package repository.

## Privacy, support and source

Recognition is local; recording is **off by default**. Do not attach typed text, traces, learned words, credentials or unreviewed logs. [Report bugs](https://github.com/itsdestin/swipe-keyboard/issues/new?template=bug.yml) with versions, app/package type, device scale/orientation and a synthetic phrase.

Optional agent assistance, including [YouCoded](https://youcoded.ai), can help diagnose errors; it is not required. The maintainer also makes YouCoded.
