# Swipe Keyboard v0.1.0-r3

English swipe typing for KDE Plasma Keyboard. **Test release.** Recognition runs on your device; recording is off by default.

## Requirements

- **Arch / CachyOS** or **Fedora 44 KDE**, x86_64, touchscreen.
- **KDE Plasma Wayland** with **Plasma Keyboard 6.7.x/6.8.x** installed—not Maliit.
- **Qt 6.11+ within Qt 6** and **glibc 2.43+**. Qt 6.11 and 6.12 are tested.

**These downloads do not support SteamOS, ARM, X11 or non-KDE desktops.** They do not install the base keyboard or upgrade your desktop. Do not force installation if dependencies are incompatible.

## 2. Install

Open a terminal in the download folder and run the command for your system:

**Arch / CachyOS**
```sh
sudo pacman -U ./swipe-keyboard-0.1.0-3-x86_64.pkg.tar.zst
```

**Fedora 44 KDE**
```sh
sudo dnf install ./swipe-keyboard-0.1.0-3.fc44.x86_64.rpm
```

## 3. Enable

Inside your logged-in KDE desktop, run **without sudo**:

```sh
swipe-keyboard check
swipe-keyboard enable
```

If a check fails, stop and follow the error. Existing custom layouts are not overwritten and need a separate migration.

**Touch** a normal text field. Select **American English / English (US)** using the globe key, then swipe `the` and `world`. The bar above the keys offers corrections for the last swiped word. Normal tapping still works.

## Remove

As the same normal user who enabled it, run:

```sh
swipe-keyboard disable
```

Then remove the package with `sudo pacman -R swipe-keyboard` or `sudo dnf remove swipe-keyboard`.

## Changes and limitations

This revision improves gesture cancellation, selection safeguards and compatibility with newer Qt 6 runtimes. It supersedes the earlier v0.1.0 packages. See the [verification report](https://github.com/itsdestin/swipe-keyboard/blob/main/docs/revision3-verification.md) for exact test scope.

English swipe only; no next-word prediction. Keyboard appearance and safe word replacement depend on application text-input support. Firefox physical Ctrl+A/Delete can cause an extra leading space. There is no automatic update feed or AUR/COPR repository yet.

For support, include `swipe-keyboard check`, the app/version and a reproduction using made-up text. **Do not attach passwords, typing recordings or unreviewed logs.**
