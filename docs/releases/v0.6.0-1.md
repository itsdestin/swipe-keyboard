# OpenSwipe v0.6.0-1

> **Installed before 30 October 2026 (older than version 0.5.1-1)?** Install it once more from the
> [README](../../README.md#install). Older versions can't find updates after the move to the new name. After that it
> updates itself.

[Downloads](https://github.com/itsdestin/openswipe/releases/tag/v0.6.0-1) · Install steps: [README](../../README.md#install). Full list of changes: [CHANGELOG](../../CHANGELOG.md).

Swipe Keyboard is now **OpenSwipe**, and it runs on more KDE systems. Typing and word choice are the same as 0.5.1.

## What changed

- **New name: OpenSwipe.** Same keyboard, same settings and learned words. The package and the `swipe-keyboard`
  command keep their names, so nothing you typed into a terminal before stops working. Old project links forward to
  the new ones.
- **New systems:** Kubuntu 26.10, Debian testing and openSUSE Tumbleweed get their own package, which updates itself
  once a day. Those updates change only this package: if an update would also upgrade, downgrade or remove anything
  else on your system, it is skipped.
- **Older KDE systems** (Kubuntu 26.04, Debian 13, openSUSE Leap 16) can use the Flatpak (KDE Plasma 6.3 or newer):
  the Steam Deck download, without Gaming Mode. It follows the desktop's light/dark setting.
- **Bazzite:** Desktop Mode and Gaming Mode, like the Steam Deck.
- **Gaming Mode** gets its words ready as soon as Steam's keyboard opens, so the first swipe comes back faster, and
  keeps them ready for 60 minutes (was 10). A word swiped right after tapped letters gets a space first, as on the
  desktop.
- **Never left without an on-screen keyboard:** removing this version, the regular package or the Flatpak, even
  without turning it off first, hands the on-screen keyboard back to your system's own.
- **Moving from the Flatpak to a regular package** keeps the words the keyboard learned.

## What to know before upgrading

- Installed 0.5.1-1? Nothing to do: it updates itself, Steam Decks included.
- Steam Deck and Bazzite Gaming Mode are still a preview, tested only in virtual machines.
- The new systems were tested in virtual machines and in automatic install, check and removal runs, not on real
  devices yet. openSUSE Leap 16 has not been tried.
- Debian testing and Tumbleweed change fast. If their package ever fails to build, a release may come out without
  it; the other systems are not held back.

| System | Installable file |
|---|---|
| Arch / CachyOS, x86_64 | `swipe-keyboard-0.6.0-1-x86_64.pkg.tar.zst` |
| Fedora 44 KDE / Plasma Mobile, x86_64 | `swipe-keyboard-0.6.0-1.fc44.x86_64.rpm` |
| Fedora 44 Plasma Mobile, ARM64 / aarch64 | `swipe-keyboard-0.6.0-1.fc44.aarch64.rpm` |
| Kubuntu 26.10, x86_64 | `swipe-keyboard_0.6.0-1.kubuntu26.10_amd64.deb` |
| Steam Deck / Bazzite Desktop Mode, older KDE, x86_64 | `swipe-keyboard-0.6.0-1-x86_64.flatpak` |
| Steam Deck / Bazzite Gaming Mode (preview), older KDE, x86_64 | `swipe-keyboard-0.6.0-1-steamos-x86_64.tar.gz` (also contains the Desktop Mode keyboard) |

Also in this release when their build passed: Debian testing (`swipe-keyboard_0.6.0-1.debiantesting_amd64.deb`) and
openSUSE Tumbleweed (`swipe-keyboard-0.6.0-1.tumbleweed.x86_64.rpm`).
