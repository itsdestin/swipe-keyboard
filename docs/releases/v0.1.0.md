# Swipe Keyboard v0.1.0 — first public test release

English swipe typing for KDE Plasma Keyboard, **Powered by FUTO Swipe**. Independent of ASUS/Z13 hardware, tablet layouts, theming and YouCoded.

## Downloads

Choose the native package for your distribution, not GitHub's automatic source ZIP:

| File | Tested target |
|---|---|
| `swipe-keyboard-0.1.0-1-x86_64.pkg.tar.zst` | Current Arch / CachyOS x86_64; Plasma Keyboard 6.8.0, Qt 6.12.0 |
| `swipe-keyboard-0.1.0-1.fc44.x86_64.rpm` | Updated Fedora 44 KDE x86_64; Plasma Keyboard 6.7.5, Qt 6.11.2 |

| `README-FIRST.md` | Setup/removal instructions, compatibility and license information |

**KDE Plasma Wayland and a touchscreen are required.** Qt major/minor must match the package build. Other desktops, X11, ARM and non-English swipe recognition are not supported by this release. Update Fedora normally before installing on an old release-ISO baseline.

After installing the matching package, run as the normal logged-in KDE user, not sudo:

```sh
swipe-keyboard check
swipe-keyboard enable
```

Select **English (US)** and touch a supported text field. Before native package removal, run `swipe-keyboard disable` as that same user.

See the [full setup guide](https://github.com/itsdestin/swipe-keyboard#install). Do not use the legacy developer `install.sh` as the standalone end-user installer. Existing custom keyboard overlays need explicit migration rather than being overwritten.

## Included

- Local English swipe recognition, word alternatives and ordinary tapping.
- First Backspace after a swipe/alternative undoes the word when exact context is available. Later typing/cursor changes or uncertain/sensitive context keep ordinary deletion.
- Reversible per-user activation without changing your panels, theme, gestures or tablet mode.
- Compiled recognition code, required models and dictionary: no user-side compilation or training-corpus download.
- Recording off by default, with owner-only opt-in development recordings and sensitive-field checks.

## Verification and limits

Both native builds passed 15 native suites plus setup/packaging checks, and their extracted runtimes loaded the real stock InputPanel with active recognition. Arch install/check/removal passed in an isolated distro root. The exact Fedora RPM additionally passed full KDE VM activation, swipe typing, whole-word/suggestion undo, settings restoration and removal. Earlier full-VM tests included Firefox Wayland fields, scaling, password safeguards, reinstall and reboot. This is a **test release**, not a guarantee for every device or app.

**Known Firefox issue:** physical Ctrl+A/Delete can leave field information stale; the next swipe may insert an unwanted leading space. Apps with missing/stale context cannot guarantee automatic word correction/deletion or keyboard summoning. See [known limits](https://github.com/itsdestin/swipe-keyboard#known-v1-limits).

There is no AUR/COPR repository or automatic update feed yet. Install future matching packages from GitHub Releases.
