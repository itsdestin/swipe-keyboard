# M0 — Swipe Typing on the Z13 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Destin can swipe words on his Plasma on-screen keyboard: a trail follows the finger, the best guess is typed, and a guess bar offers the next two, which can be tapped to swap the word. Recognition is done by FUTO Swipe, and a scoreboard tracks accuracy on real human swipes.

**Architecture:** FUTO's GPL C++ library (`swipe-library`, vendored as a git submodule) runs FUTO's models through ExecuTorch. Our `libswipekb_engine.so` wraps it behind a small API that takes pixel traces and key rectangles. A Qt 6 QML module `SwipeKeyboard` provides `SwipeInputMethod` (a `QVirtualKeyboardAbstractInputMethod`) and `SwipeCapture.qml` (it listens to the keyboard's own touch area, draws the trail, and hands the path to the input method). touch-profile's generated layout loads both at runtime, guarded so the layout works unchanged when the module is absent.

**Tech Stack:** C++20, CMake ≥ 3.29, Qt 6.12 (Core/Gui/Qml/Quick/VirtualKeyboard/Test), GoogleTest 1.18, ExecuTorch v1.2.0 (built by FUTO's Makefile), bash + bats (`~/.local/opt/bats-core/bin/bats`), Python 3 (stdlib only).

**Spec:** `docs/superpowers/specs/2026-10-14-swipe-typing-design.md` (this plan = milestone M0, plus the basic auto-space that M0 needs to be usable).

```bash
#!/usr/bin/env bash
# fetch-assets.sh — download what the engine needs into assets/ (git-ignored: large and third-party):
#   FUTO Swipe models (FUTO Model Weights License 1.0 — products must say "Powered by FUTO Swipe"),
#   the AOSP English word list (Apache-2.0), and FUTO's real-swipe test split (MIT) for the scoreboard.
# Re-running skips files already present. Usage: scripts/fetch-assets.sh
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
A="${SWIPEKB_ASSETS:-$ROOT/assets}"
HF=https://huggingface.co/futo-org/futo-swipe/resolve/main
DS=https://huggingface.co/datasets/futo-org/swipe.futo.org/resolve/main
AOSP=https://android.googlesource.com/platform/packages/inputmethods/LatinIME/+/refs/heads/main/dictionaries/en_US_wordlist.combined.gz

get() { # url dest — download once; .part first so an interrupted download never looks complete
    [ -s "$2" ] && return 0
    mkdir -p "$(dirname "$2")"
    curl -fL --retry 3 -o "$2.part" "$1" && mv "$2.part" "$2"
}

for f in honorable_sturgeon/model_fp32.pte honorable_sturgeon/metadata.json \
         magic_macaw/model_fp32.pte magic_macaw/metadata.json \
         hungry_jellyfish/context_lm.pte hungry_jellyfish/metadata.json hungry_jellyfish/vocab.txt; do
    get "$HF/$f" "$A/models/$f"
done
get "$HF/LICENSE.md" "$A/models/FUTO-MODEL-LICENSE.md"

# WHY base64: googlesource serves raw files only as base64 text (?format=TEXT).
if [ ! -s "$A/dict/en_US_wordlist.combined" ]; then
    mkdir -p "$A/dict"
    curl -fsL "$AOSP?format=TEXT" | base64 -d | gunzip > "$A/dict/en_US_wordlist.combined.part"
    mv "$A/dict/en_US_wordlist.combined.part" "$A/dict/en_US_wordlist.combined"
fi

get "$DS/test.jsonl" "$A/eval/test.jsonl"
echo "assets ready in $A"
```

```bash
# Uses a fake infer_jsonl so these tests need no models.
setup() {
  ROOT="$BATS_TEST_DIRNAME/../.."
  export SWIPEKB_ASSETS="$BATS_TEST_TMPDIR/assets" BENCH_N=4 BENCH_HISTORY="$BATS_TEST_TMPDIR/history.tsv"

#!/usr/bin/env bash
printf 'good 1 a:a:[]\n\nResults: 4 samples\n  top-1:  3 / 4 = %s%%\n  top-4:  4 / 4 = %s%%\n  miss:   0 / 4 = 0%%\n\nTimings (avg µs per sample):\n  total:    1234.5\n' "$FAKE_TOP1" "$FAKE_TOP3"

@test "records a row and prints both scores" {

  [ "$status" -eq 0 ]
  [[ "$output" == *"first guess right: 90.5%"* ]]; [[ "$output" == *"top 3: 97.25%"* ]]
  [ "$(wc -l < "$BENCH_HISTORY")" -eq 2 ]
  tail -1 "$BENCH_HISTORY" | grep -q $'\tfirst\t4\t90.5\t97.25\t1234.5$'

  run "$ROOT/bench/score.sh" --label same --check; [ "$status" -eq 0 ]

  "$ROOT/bench/score.sh" --label base
  FAKE_TOP3=96 run "$ROOT/bench/score.sh" --label worse --check

  printf '#!/usr/bin/env bash\necho boom\n' > "$INFER_JSONL"
```

```python
"""make-slice.py SRC N DEST — write N lines spread evenly across SRC (every k-th line) to DEST.
WHY evenly spread: test.jsonl is grouped by contributor session, so the first N lines would grade
only a handful of people. Deterministic, so every scoreboard run sees the same swipes."""
import sys

src, n, dest = sys.argv[1], int(sys.argv[2]), sys.argv[3]
with open(src, encoding="utf-8") as f:
    lines = f.readlines()
step = max(1, len(lines) // n)
picked = lines[::step][:n]
with open(dest + ".part", "w", encoding="utf-8") as f:
    f.writelines(picked)
import os
os.replace(dest + ".part", dest)
```

- [ ] **Step 4: Write `bench/score.sh`**

```bash
#!/usr/bin/env bash
# bench/score.sh — the scoreboard. Replays a fixed slice of REAL human swipes (FUTO's test split, never
# trained on) through FUTO's infer_jsonl and records first-guess % and top-3 % in bench/history.tsv.
# Usage: bench/score.sh [--label TEXT] [--check]
#   --check  exit 1 if either score is below the best earlier row with the same slice size — the design's
#            rule that no change may lower the score.
# Env: INFER_JSONL, SWIPEKB_ASSETS (assets/), BENCH_N (2000), BENCH_HISTORY (bench/history.tsv)
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
A="${SWIPEKB_ASSETS:-$ROOT/assets}"
N="${BENCH_N:-2000}"
INFER="${INFER_JSONL:-$ROOT/third_party/swipe-library/build/infer_jsonl}"
HIST="${BENCH_HISTORY:-$ROOT/bench/history.tsv}"
label=manual check=0
while [ $# -gt 0 ]; do
    case "$1" in
        --label) label="$2"; shift 2 ;;
        --check) check=1; shift ;;
        *) echo "usage: bench/score.sh [--label TEXT] [--check]" >&2; exit 2 ;;
    esac
done

slice="$A/eval/bench-$N.jsonl"
[ -s "$slice" ] || python3 -I "$ROOT/bench/make-slice.py" "$A/eval/test.jsonl" "$N" "$slice"

out=$("$INFER" --encoder "$A/models/honorable_sturgeon/model_fp32.pte" \
        --decoder "$A/models/magic_macaw/model_fp32.pte" \
        --lm-model "$A/models/hungry_jellyfish/context_lm.pte" --lm-vocab "$A/models/hungry_jellyfish/vocab.txt" \
        --vocab "$A/dict/en_US_wordlist.combined" \
        --layout "$ROOT/third_party/swipe-library/models/layouts/en_qwerty.json" \
        --jsonl "$slice" --top-k 3 --beam-width 100 --expansion 2>&1) || true
top1=$(awk '/^  top-1:/ { gsub("%", "", $NF); print $NF }' <<<"$out")
# WHY "top-4": infer_jsonl always labels its "in the top-k" line top-4; with --top-k 3 it is the top-3 score.
top3=$(awk '/^  top-4:/ { gsub("%", "", $NF); print $NF }' <<<"$out")
us=$(awk '/^  total:/ { print $NF }' <<<"$out")
if [ -z "$top1" ] || [ -z "$top3" ]; then
    { echo "score.sh: could not read infer_jsonl output:"; tail -20 <<<"$out"; } >&2
    exit 1
fi

[ -f "$HIST" ] || printf 'date\tcommit\tlabel\tn\ttop1\ttop3\tavg_us\n' > "$HIST"
read -r best1 best3 < <(awk -F'\t' -v n="$N" 'NR > 1 && $4 == n { if ($5 > b1) b1 = $5; if ($6 > b3) b3 = $6 }
                                             END { print (b1 == "" ? -1 : b1), (b3 == "" ? -1 : b3) }' "$HIST")
commit=$(git -C "$ROOT" rev-parse --short HEAD 2>/dev/null || echo none)
printf '%s\t%s\t%s\t%s\t%s\t%s\t%s\n' "$(date +%F)" "$commit" "$label" "$N" "$top1" "$top3" "${us:-?}" >> "$HIST"
echo "first guess right: $top1%   right word in top 3: $top3%   ($N real swipes, avg ${us:-?} µs)"

if [ "$check" = 1 ] && awk -v a="$top1" -v b="$best1" -v c="$top3" -v d="$best3" 'BEGIN { exit !(a < b || c < d) }'; then
    echo "FAIL: below the best so far (first guess $best1%, top 3 $best3%)"
    exit 1
fi
```

- [ ] **Step 3: Write the public header `engine/include/swipekb/recognizer.hpp`**

```cpp
// swipekb engine — turns a finger path over the on-screen keyboard into ranked word guesses.
// Wraps FUTO Swipe; this header deliberately exposes no FUTO or ExecuTorch types so callers (the Qt
// plugin) never compile against them.
#pragma once

#include <memory>
#include <optional>
#include <string>
#include <vector>

namespace swipekb {

struct TracePoint {
    float x, y;   // pixels, keyboard coordinates
    float t_ms;   // milliseconds since the swipe started
};

struct KeyRect {
    char letter;          // 'a'..'z' (upper case accepted, lower-cased)
    float x, y, w, h;     // top-left corner and size, same pixel space as the trace
};

struct Candidate {
    std::string word;
    float score;
};

// FUTO's models expect key centers and trace points in 0..1 coordinates of the letter area
// (left edge of the leftmost letter key = 0, right edge of the rightmost = 1; same for rows).
struct NormalizedInput {
    std::string letters;                 // always "abcdefghijklmnopqrstuvwxyz"
    std::vector<float> key_cx, key_cy;   // [26], indexed like `letters`
    std::vector<float> x, y, t;          // trace, same length
};

// nullopt unless all 26 letters are present and the trace has at least 2 points.
std::optional<NormalizedInput> normalize(const std::vector<TracePoint> &trace, const std::vector<KeyRect> &keys);
```

```cpp
#include "swipekb/recognizer.hpp"

#include <algorithm>
#include <cctype>
#include <limits>

namespace swipekb {

std::optional<NormalizedInput> normalize(const std::vector<TracePoint> &trace, const std::vector<KeyRect> &keys)
{
    if (trace.size() < 2)
        return std::nullopt;

    // Letter area = bounding box of all letter keys. FUTO's coordinates are relative to it, so the
    // number row, space bar etc. never stretch the space.
    float minX = std::numeric_limits<float>::max(), minY = minX;
    float maxX = std::numeric_limits<float>::lowest(), maxY = maxX;
    NormalizedInput out;
    out.letters = "abcdefghijklmnopqrstuvwxyz";
    out.key_cx.assign(26, -1.f);
    out.key_cy.assign(26, -1.f);
    std::vector<const KeyRect *> byLetter(26, nullptr);
    for (const KeyRect &k : keys) {
        const int c = std::tolower(static_cast<unsigned char>(k.letter));
        if (c < 'a' || c > 'z')
            continue;
        byLetter[c - 'a'] = &k;
        minX = std::min(minX, k.x);
        minY = std::min(minY, k.y);
        maxX = std::max(maxX, k.x + k.w);
        maxY = std::max(maxY, k.y + k.h);
    }
    if (std::find(byLetter.begin(), byLetter.end(), nullptr) != byLetter.end())
        return std::nullopt;
    const float w = maxX - minX, h = maxY - minY;
    if (w <= 0 || h <= 0)
        return std::nullopt;

    for (int i = 0; i < 26; ++i) {
        out.key_cx[i] = (byLetter[i]->x + byLetter[i]->w / 2 - minX) / w;
        out.key_cy[i] = (byLetter[i]->y + byLetter[i]->h / 2 - minY) / h;
    }
    out.x.reserve(trace.size());
    out.y.reserve(trace.size());
    out.t.reserve(trace.size());
    for (const TracePoint &p : trace) {
        out.x.push_back((p.x - minX) / w);
        out.y.push_back((p.y - minY) / h);
        out.t.push_back(p.t_ms);
    }
    return out;
}

} // namespace swipekb
```

```cpp
#include "swipe_decoder/trie.hpp"

namespace swipekb {

struct Recognizer::Impl {
    // Declared before `engine` so it is destroyed after it: the engine keeps a pointer into the dictionary.
    std::optional<swipe_decoder::Trie> dict;
    swipe_decoder::SwipeEngine engine;
    swipe_decoder::KeyboardLayout layout; // what the engine currently uses
    bool ready = false;
};

static bool fileExists(const std::string &p) { return !p.empty() && std::ifstream(p).good(); }

// WHY compare: the keyboard re-measures its keys on every swipe; only re-configure FUTO's engine when
// the geometry actually changed (window resize, rotation), not on every swipe.
static bool sameGeometry(const swipe_decoder::KeyboardLayout &l, const NormalizedInput &n)
{
    if (l.key_cx.size() != n.key_cx.size() || l.letters != n.letters)
        return false;
    for (size_t i = 0; i < n.key_cx.size(); ++i)
        if (std::fabs(l.key_cx[i] - n.key_cx[i]) > 1e-4f || std::fabs(l.key_cy[i] - n.key_cy[i]) > 1e-4f)
            return false;
    return true;
}

Recognizer::Recognizer() : impl_(std::make_unique<Impl>()) {}
Recognizer::~Recognizer() = default;

bool Recognizer::init(const ModelPaths &p)
{
    impl_ = std::make_unique<Impl>();
    try {
        if (!fileExists(p.encoder) || !fileExists(p.dictionary)) {
            std::fprintf(stderr, "swipekb: missing encoder or dictionary (%s, %s)\n", p.encoder.c_str(), p.dictionary.c_str());
            return false;
        }
        impl_->dict = swipe_decoder::load_trie_simple(p.dictionary);
        if (!impl_->dict) {
            std::fprintf(stderr, "swipekb: could not read dictionary %s\n", p.dictionary.c_str());
            return false;
        }
        swipe_decoder::SwipeEngine::Config cfg;
        cfg.encoder_path = p.encoder;
        if (fileExists(p.decoder))
            cfg.decoder_path = p.decoder;
        if (fileExists(p.lm_model) && fileExists(p.lm_vocab)) {
            cfg.lm_model_path = p.lm_model;
            cfg.lm_vocab_path = p.lm_vocab;
        }
        cfg.layout = swipe_decoder::default_en_qwerty();
        cfg.dictionaries = {impl_->dict->itrie()};
        if (!impl_->engine.init(cfg)) {
            std::fprintf(stderr, "swipekb: FUTO engine init failed\n");
            impl_ = std::make_unique<Impl>();
            return false;
        }
        impl_->layout = cfg.layout;
        impl_->ready = true;
        return true;
    } catch (const std::exception &e) {
        std::fprintf(stderr, "swipekb: init failed: %s\n", e.what());
        impl_ = std::make_unique<Impl>();
        return false;
    }
}

bool Recognizer::ready() const { return impl_->ready; }

std::vector<Candidate> Recognizer::recognize(const std::vector<TracePoint> &trace, const std::vector<KeyRect> &keys,
                                             const std::vector<std::string> &context, int top_k)
{
    if (!impl_->ready || top_k <= 0)
        return {};
    const auto n = normalize(trace, keys);
    if (!n)
        return {};
    try {
        if (!sameGeometry(impl_->layout, *n)) {
            auto layout = swipe_decoder::make_layout(n->letters, n->key_cx.data(), n->key_cy.data(),
                                                     static_cast<int>(n->key_cx.size()));
            swipe_decoder::SwipeEngine::Mode mode;
            mode.layout = layout;
            if (!impl_->engine.setMode(mode))
                return {};
            impl_->layout = layout;
        }
        const auto words = impl_->engine.recognize(n->x.data(), n->y.data(), n->t.data(), n->x.size(), context, top_k);
        std::vector<Candidate> out;
        out.reserve(words.size());
        for (const auto &w : words)
            out.push_back({w.word, w.final_score});
        return out;
    } catch (const std::exception &e) {
        std::fprintf(stderr, "swipekb: recognize failed: %s\n", e.what());
        return {};
    }
}
```

```cpp
// SwipeSession — the text decisions around one swiped word: whether it needs a space before it, its
// capitalization, the guess-bar alternatives, and swapping the typed word for one of them.
// No keyboard or engine here, so every rule is unit-tested (tests/tst_swipesession.cpp).
#pragma once

#include <QString>
#include <QStringList>

// Replace `replaceLength` characters starting `replaceFrom` characters from the cursor (negative = before
// it) with `text`. An empty plan means "send nothing".
struct CommitPlan {
    QString text;
    int replaceFrom = 0;
    int replaceLength = 0;
    bool isEmpty() const { return text.isEmpty() && replaceLength == 0; }
};

enum class CaseMode { AsIs, Capitalize, AllCaps };

class SwipeSession {
public:
    // Last `max` words of the current sentence, oldest first, punctuation trimmed (context for the guesses).
    static QStringList contextWords(const QString &textBeforeCursor, int max = 3);
    // True when the swiped word must be preceded by a space (Gboard-style auto-space).
    static bool needsSpaceBefore(const QString &textBeforeCursor);

    // Starts a new session from the engine's best-first guesses. Empty plan if there are none.
    CommitPlan commitSwipe(const QString &textBeforeCursor, const QStringList &candidates, CaseMode mode);
    // Replaces the typed word with alternatives()[index]. Empty plan if inactive or out of range.
    CommitPlan swapToAlternative(int index);
    // The guesses not currently typed, best first, with the session's capitalization.
    QStringList alternatives() const;
    // False once the user has typed or moved the cursor away from the swiped word.
    bool cursorStillAfterWord(const QString &textBeforeCursor) const;
    void clear();
    bool isActive() const { return m_current >= 0; }

private:
    static QString applyCase(const QString &word, CaseMode mode);

    QStringList m_candidates;
    int m_current = -1;
    CaseMode m_mode = CaseMode::AsIs;
    QString m_typedWord;
};
```

```cpp
#include "swipesession.h"

#include <QRegularExpression>
#include <algorithm>

QStringList SwipeSession::contextWords(const QString &textBeforeCursor, int max)
{
    // Only the current sentence counts: after . ! ? the next word starts fresh, like Gboard.
    QString sentence = textBeforeCursor;
    const qsizetype end = std::max({sentence.lastIndexOf(u'.'), sentence.lastIndexOf(u'!'), sentence.lastIndexOf(u'?')});
    if (end >= 0)
        sentence = sentence.mid(end + 1);

    QStringList words;
    for (QString w : sentence.split(QRegularExpression(QStringLiteral("\\s+")), Qt::SkipEmptyParts)) {
        while (!w.isEmpty() && w.front().isPunct())
            w.remove(0, 1);
        while (!w.isEmpty() && w.back().isPunct())
            w.chop(1);
        if (!w.isEmpty())
            words << w;
    }
    return words.mid(std::max<qsizetype>(0, words.size() - max));
}

bool SwipeSession::needsSpaceBefore(const QString &textBeforeCursor)
{
    if (textBeforeCursor.isEmpty())
        return false;
    const QChar c = textBeforeCursor.back();
    // WHY: right after an opening bracket/quote, a hyphen, slash, @ or # the word belongs glued on.
    static const QString glue = QStringLiteral("([{\"'“‘-/@#");
    return !c.isSpace() && !glue.contains(c);
}

QString SwipeSession::applyCase(const QString &word, CaseMode mode)
{
    switch (mode) {
    case CaseMode::AllCaps:
        return word.toUpper();
    case CaseMode::Capitalize:
        return word.isEmpty() ? word : word.front().toUpper() + word.mid(1);
    case CaseMode::AsIs:
        break;
    }
    return word;
}

CommitPlan SwipeSession::commitSwipe(const QString &textBeforeCursor, const QStringList &candidates, CaseMode mode)
{
    clear();
    if (candidates.isEmpty())
        return {};
    m_candidates = candidates;
    m_current = 0;
    m_mode = mode;
    m_typedWord = applyCase(candidates.front(), mode);
    return {(needsSpaceBefore(textBeforeCursor) ? QStringLiteral(" ") : QString()) + m_typedWord, 0, 0};
}

QStringList SwipeSession::alternatives() const
{
    QStringList out;
    for (int i = 0; i < m_candidates.size(); ++i)
        if (i != m_current)
            out << applyCase(m_candidates.at(i), m_mode);
    return out;
}

CommitPlan SwipeSession::swapToAlternative(int index)
{
    if (!isActive() || index < 0 || index >= m_candidates.size() - 1)
        return {};
    const int target = index < m_current ? index : index + 1; // skip the typed word in the list
    const QString old = m_typedWord;
    m_current = target;
    m_typedWord = applyCase(m_candidates.at(target), m_mode);
    return {m_typedWord, -static_cast<int>(old.size()), static_cast<int>(old.size())};
}

bool SwipeSession::cursorStillAfterWord(const QString &textBeforeCursor) const
{
    return isActive() && textBeforeCursor.endsWith(m_typedWord);
}

void SwipeSession::clear()
{
    m_candidates.clear();
    m_current = -1;
    m_mode = CaseMode::AsIs;
    m_typedWord.clear();
}
```

```cpp
// WHY one shared engine per process: Qt recreates the input method whenever the layout is rebuilt, and
// reloading the models each time would add a visible pause.
static swipekb::Recognizer &recognizer()
{
    static swipekb::Recognizer r;
    static const bool loaded = [] {
        QString dir = qEnvironmentVariable("SWIPEKB_DATA");
        if (dir.isEmpty())
            dir = QStandardPaths::writableLocation(QStandardPaths::GenericDataLocation) + QStringLiteral("/swipe-keyboard");
        swipekb::ModelPaths paths = swipekb::ModelPaths::fromDir(dir.toStdString());
        if (qEnvironmentVariableIntValue("SWIPEKB_NO_DECODER"))
            paths.decoder.clear();
        const bool ok = r.init(paths);
        if (!ok)
            qCWarning(lcSwipe) << "swipe engine not loaded from" << dir << "- swiping disabled, tapping unaffected";
        return ok;
    }();
    Q_UNUSED(loaded);
    return r;
}

void SwipeInputMethod::finishSwipe(const QVariantList &points, const QVariantList &keys)
{
    QVirtualKeyboardInputContext *ic = inputContext();
    if (!ic || !recognizer().ready())
        return;
    QElapsedTimer timer;
    timer.start();

    std::vector<swipekb::TracePoint> trace;
    trace.reserve(points.size());
    for (const QVariant &v : points) {
        const QVariantMap m = v.toMap();
        trace.push_back({m.value("x").toFloat(), m.value("y").toFloat(), m.value("t").toFloat()});
    }
    std::vector<swipekb::KeyRect> rects;
    for (const QVariant &v : keys) {
        const QVariantMap m = v.toMap();
        const QString letter = m.value("letter").toString();
        if (letter.size() != 1)
            continue;
        rects.push_back({letter.at(0).toLatin1(), m.value("x").toFloat(), m.value("y").toFloat(),
                         m.value("w").toFloat(), m.value("h").toFloat()});
    }

    const QString before = textBeforeCursor();
    std::vector<std::string> context;
    for (const QString &w : SwipeSession::contextWords(before))
        context.push_back(w.toStdString());

    QStringList candidates;
    for (const auto &c : recognizer().recognize(trace, rects, context, 3))
        candidates << QString::fromStdString(c.word);

    const CaseMode mode = ic->isCapsLockActive() ? CaseMode::AllCaps
        : m_textCase == QVirtualKeyboardInputEngine::TextCase::Upper ? CaseMode::Capitalize
                                                                       : CaseMode::AsIs;
    const CommitPlan plan = m_session.commitSwipe(before, candidates, mode);
    if (!plan.isEmpty())
        ic->commit(plan.text, plan.replaceFrom, plan.replaceLength);
    refreshGuessBar();
    qCInfo(lcSwipe) << "swipe" << trace.size() << "points ->" << candidates << "in" << timer.elapsed() << "ms";
}

void SwipeInputMethod::clearSession()
{
    if (!m_session.isActive())
        return;
    m_session.clear();
    refreshGuessBar();
}

void SwipeInputMethod::refreshGuessBar()
{
    emit selectionListChanged(Type::WordCandidateList);
    emit selectionListActiveItemChanged(Type::WordCandidateList, -1);
}
```

```qml
import QtQuick
import QtQuick.VirtualKeyboard

// SwipeCapture — swipe-keyboard's finger listener and trail.
// WHY a separate layer: Qt's keyboard records paths only in handwriting boxes, never across keys.
// It only LISTENS to the keyboard's own touch area, so taps work exactly as before. Once a finger that
// started on a letter drags past `threshold`, it cancels that key press, draws the trail, and on lift
// hands the path to SwipeInputMethod. It must never sit inside the layout: Qt finds the key under a
// finger with childAt() on the layout, and an overlay there would swallow every tap.
Canvas {
    id: root

    required property Item layoutItem   // the KeyboardLayout (to find the letter keys)
    required property Item touchArea    // Qt VK's keyboard.keyboardInputArea

    anchors.fill: parent
    enabled: false                      // never takes input itself
    z: 1000

    property color trailColor: "#3daee9" // Breeze highlight blue
    // Drag distance (fraction of a key width) before a touch counts as a swipe. Tuned in M1.
    property real thresholdKeys: 0.5

    property var points: []
    property int trackedId: -1
    property real startTime: 0
    property Item startKey: null
    property bool swiping: false

    function isLetterKey(item) {
        return !!item && item.key !== undefined && item.key >= Qt.Key_A && item.key <= Qt.Key_Z
    }

    function letterKeys() {
        var out = []
        function walk(item) {
            for (var i = 0; i < item.children.length; ++i) {
                var c = item.children[i]
                if (root.isLetterKey(c)) {
                    if (c.visible) {
                        var p = c.mapToItem(root.touchArea, 0, 0)
                        out.push({ letter: String(c.text).toLowerCase(), x: p.x, y: p.y, w: c.width, h: c.height })
                    }
                } else {
                    walk(c)
                }
            }
        }
        walk(layoutItem)
        return out
    }

    function trackedPoint(touchPoints) {
        for (var i = 0; i < touchPoints.length; ++i)
            if (touchPoints[i].pointId === trackedId)
                return touchPoints[i]
        return null
    }

    function stop() {
        trackedId = -1
        points = []
        swiping = false
        startKey = null
        requestPaint()
    }

    Connections {
        target: root.touchArea

        function onPressed(touchPoints) {
            if (root.trackedId !== -1) {     // a second finger: not a swipe
                if (!root.swiping)
                    root.stop()
                return
            }
            var im = InputContext.inputEngine.inputMethod
            if (!im || typeof im.finishSwipe !== "function" || !im.isReady())
                return
            var tp = touchPoints[0]
            root.trackedId = tp.pointId
            root.startTime = Date.now()
            root.points = [{ x: tp.x, y: tp.y, t: 0 }]
            root.startKey = root.touchArea.keyOnPoint(tp.x, tp.y)
        }

        function onUpdated(touchPoints) {
            var tp = root.trackedPoint(touchPoints)
            if (!tp)
                return
            root.points.push({ x: tp.x, y: tp.y, t: Date.now() - root.startTime })
            if (!root.swiping && root.isLetterKey(root.startKey)) {
                var dx = tp.x - root.points[0].x, dy = tp.y - root.points[0].y
                if (Math.sqrt(dx * dx + dy * dy) > root.startKey.width * root.thresholdKeys) {
                    root.swiping = true
                    // Cancels Qt's pending key press so lifting the finger types no letter.
                    root.touchArea.reset()
                }
            }
            if (root.swiping)
                root.requestPaint()
        }

        function onReleased(touchPoints) {
            var tp = root.trackedPoint(touchPoints)
            if (!tp)
                return
            if (root.swiping) {
                root.points.push({ x: tp.x, y: tp.y, t: Date.now() - root.startTime })
                InputContext.inputEngine.inputMethod.finishSwipe(root.points, root.letterKeys())
            }
            root.stop()
        }

        function onCanceled(touchPoints) {
            if (root.trackedPoint(touchPoints))
                root.stop()
        }
    }

    onPaint: {
        var ctx = getContext("2d")
        ctx.reset()
        if (!swiping || points.length < 2)
            return
        ctx.lineWidth = 8
        ctx.lineCap = "round"
        ctx.lineJoin = "round"
        ctx.globalAlpha = 0.8
        ctx.strokeStyle = trailColor
        ctx.beginPath()
        ctx.moveTo(points[0].x, points[0].y)
        for (var i = 1; i < points.length; ++i)
            ctx.lineTo(points[i].x, points[i].y)
        ctx.stroke()
    }
```

- [ ] **Step 1: Write `install.sh`**

```bash
#!/usr/bin/env bash
# install.sh — build swipe-keyboard, run its tests, and install it where Plasma Keyboard loads it:
#   ~/.local/share/swipe-keyboard/{qml/SwipeKeyboard, models, dict}. touch-profile's layout + wrapper pick it up
#   (their hook does nothing when this folder is missing), then the on-screen keyboard is restarted.
# Usage: ./install.sh              build + test + install + restart
#        ./install.sh --no-restart  same, but leave the running keyboard alone
#        ./install.sh --uninstall   remove qml/models/dict (personal data like traces/ is kept) + restart
set -euo pipefail
ROOT="$(cd "$(dirname "$0")" && pwd)"
DEST="${XDG_DATA_HOME:-$HOME/.local/share}/swipe-keyboard"

restart_keyboard() {
    # WHY: KWin owns the keyboard process and starts a fresh one after it exits; the new one loads the new files.
    local pid
    pid=$(pidof plasma-keyboard || true)
    [ -n "$pid" ] && kill $pid
    for _ in 1 2 3 4 5 6; do
        sleep 1
        if pidof plasma-keyboard >/dev/null; then echo "on-screen keyboard restarted"; return 0; fi
    done
    echo "on-screen keyboard not running — KWin starts it the next time a text field needs it" >&2
}

case "${1:-}" in
    --uninstall)
        rm -rf "$DEST/qml" "$DEST/models" "$DEST/dict"
        restart_keyboard
        echo "swipe typing removed (keyboard back to plain tapping)"
        exit 0 ;;
    --no-restart|"") ;;
    *) echo "usage: ./install.sh [--no-restart|--uninstall]" >&2; exit 2 ;;
esac

"$ROOT/scripts/fetch-assets.sh"
[ -f "$ROOT/third_party/swipe-library/third_party/executorch/cmake-out-host/libexecutorch.a" ] || "$ROOT/scripts/build-futo.sh"
cmake -S "$ROOT" -B "$ROOT/build" -DCMAKE_BUILD_TYPE=Release
cmake --build "$ROOT/build" -j"$(nproc)"
(cd "$ROOT/build" && ctest --output-on-failure)

mkdir -p "$DEST"
# Stage then swap, so a half-copied module is never what the keyboard loads.
rm -rf "$DEST/.qml.new" && cp -r "$ROOT/build/qml" "$DEST/.qml.new" && rm -rf "$DEST/qml" && mv "$DEST/.qml.new" "$DEST/qml"
rm -rf "$DEST/models" "$DEST/dict"
cp -r "$ROOT/assets/models" "$DEST/models"
cp -r "$ROOT/assets/dict" "$DEST/dict"
echo "installed to $DEST"
[ "${1:-}" = --no-restart ] || restart_keyboard
```
